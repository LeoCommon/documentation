# Welcome to the LeoCommon Documentation
LeoCommon is a Ground Station Observatory Network for LEO Satellite Communication Research. 

## Getting Started

In case you want to simply start your own network, have a look at our [quick-start guide](./quick_start/quick_start_guide.md). This allows a simple setup of some ground stations that connect to your server and execute some basic tasks. 
However this simple setup comes with some drawbacks, as no individual updates. For updates you will rely on new releases in this repository. 

For a proper setup, with fully independence, it is necessary to compile the ground station operating system by your own. You can do this, following our [full-setup guide](./full_setup/full_setup_guide.md).

For common problems and trouble-shootings, see our [trouble-shooting guide](./trouble_shooting.md).

To get an overview of the security in the LeoCommon System, see our [security guide](./security_guide.md).
